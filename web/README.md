# Habit Tracker: aplikacja web

Aplikacja Next.js 16 + Supabase. Opis projektu, stan prac, uruchomienie i testy: [README w katalogu głównym](../README.md).

Skrypty (`npm run <nazwa>`): `dev`, `build`, `start`, `lint`, `test`, `test:db`, `test:e2e`.

Uwaga: Next.js 16 różni się od starszych wersji (np. `proxy.ts` zamiast `middleware.ts`). Dokumentacja odpowiadająca zainstalowanej wersji leży w `node_modules/next/dist/docs/`, o czym przypomina też [AGENTS.md](AGENTS.md).
